# Папка видео-перебивок

Все короткие перебивки (b-roll) лежат в этой папке. Подпапки разрешены.

Положите сюда видеофайлы (`.mp4`, `.mov`, `.mkv`, `.avi`, `.webm`, `.m4v`).
Перебивки выбираются вручную в GUI. Давайте файлам говорящие имена, например
`gorko.mp4`, `romantika.mp4`, `deneg_reshayut.mp4`.
