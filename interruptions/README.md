# Папка видео-перебивок

Все короткие перебивки (b-roll) лежат **в одной папке**, без категорий и подпапок.

Положите сюда видеофайлы (`.mp4`, `.mov`, `.mkv`, `.avi`, `.webm`, `.m4v`).
Нейросеть при монтаже выбирает, какую перебивку вставить после реплики,
исходя из содержания расшифровки и **имён файлов** — поэтому давайте файлам
говорящие имена (например `gorko.mp4`, `romantika.mp4`, `deneg_reshayut.mp4`).

Тестовые заглушки можно сгенерировать скриптом:

```bat
.venv\Scripts\python.exe generate_placeholders.py
```
