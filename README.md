# InterviewKit

Программа для автоматического монтажа свадебных/праздничных интервью с прикольными
видео-перебивками.

**Сценарий работы:** вы записываете интервью на телефон/камеру, готовый mp4
кладёте в папку `incoming/` — программа извлекает аудио, распознаёт речь
локальной нейросетью Whisper, находит ключевые слова и вставляет между ответами
видео-перебивки из папки `interruptions/`. На выходе — один смонтированный
фильм на интервью.

## Возможности

- Локальное распознавание речи (faster-whisper) — без интернета, бесплатно.
- Автоматическая нарезка речи по паузам (silence detection).
- Вставка видео-перебивок по ключевым словам (`keywords.json`).
- Просмотр расшифровки и ручная правка перебивок перед сборкой.
- Переносимая сборка в один `.exe` (без установленного Python).

## Структура папок

```
interview_kit/
├── interview_app.py        # точка входа + GUI
├── core/                   # модули ядра
│   ├── paths.py            # разрешение путей
│   ├── config.py           # конфигурация
│   ├── ffmpeg_wrapper.py   # обёртка над ffmpeg
│   ├── stt.py              # локальный Whisper
│   ├── keywords.py         # поиск ключевых слов
│   ├── editor.py           # план монтажа и сборка
│   └── pipeline.py         # оркестрация пайплайна
├── config.example.json     # пример настроек (при первом запуске → config.json)
├── keywords.json           # ключевое слово → категории перебивок
├── requirements.txt
├── build.bat               # сборка в exe
├── interruptions/          # видео-перебивки (по папкам-категориям)
│   ├── love/
│   ├── wedding/
│   └── ...
├── incoming/               # сюда кладёте свежие записи (один mp4 = одно интервью)
├── interviews/             # сюда складываются результаты
└── models/                 # модель Whisper для офлайн-работы
```

## Запуск из исходников

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python interview_app.py
```

Требуется установленный **ffmpeg** в PATH, либо положите `ffmpeg.exe` в
`bin\ffmpeg.exe` рядом с проектом.

> ⚠️ При первом запуске модель Whisper (`small`) скачается автоматически
> (~500 МБ) в кэш HuggingFace. Для офлайн-сборки см. раздел ниже.

## Использование

1. Положите видеозапись интервью в папку `incoming/`
   (например `2026-10-27_Иван.mp4`).
2. Запустите программу, выберите файл в списке, укажите имя гостя.
3. Нажмите **«Подготовить расшифровку»** — программа извлечёт аудио,
   распознает речь и построит план монтажа.
4. Во вкладке **«Расшифровка»** проверьте текст и перебивки:
   любую перебивку можно заменить на другую или убрать.
5. Нажмите **«🎬 Собрать итоговое видео»** — получите `final.mp4`
   в папке `interviews/<дата>_<гость>/`.

## Ключевые слова и категории

Файл `keywords.json` связывает ключевые слова с категориями перебивок:

```json
{
  "любовь": ["love", "romantic"],
  "алкоголь": ["alcohol", "party"]
}
```

Если в расшифрованном ответе встретилось слово «любовь», программа возьмёт
случайную перебивку из папки `interruptions/love/` (или `interruptions/romantic/`)
и вставит её после этого ответа.

Добавляйте свои категории: создайте папку в `interruptions/` и пропишите её
в `keywords.json`.

## Настройки

Кнопка **«Настройки»** в программе или правьте `config.json` напрямую:

| Параметр | Описание |
|----------|----------|
| `whisper_model` | Размер модели: `tiny`/`base`/`small`/`medium`/`large-v3` |
| `silence_db` | Порог тишины (dB). Громче праздника → меньше порог (напр. -25) |
| `silence_min_duration` | Мин. длительность паузы, сек |
| `fallback_segment_sec` | Длина отрезка, если пауз нет (монолог) |
| `output_resolution` | Разрешение итогового видео |
| `output_fps` | FPS итогового видео |

## Офлайн-сборка модели Whisper

Чтобы exe работал без интернета на чужом компе:

1. Один раз запустите программу из исходников (с интернетом) — модель
   скачается в кэш.
2. Либо скачайте CTranslate2-модель вручную и положите в `models/small/`
   (должен быть файл `model.bin`).
3. После сборки exe скопируйте папку `models/` рядом с `interview_app.exe`.

Программа сначала ищет модель в `models/<имя>/`, и только если её нет —
пробует скачать.

## Сборка в exe

```bat
build.bat
```

Скрипт:
1. Установит зависимости.
2. Соберёт `dist/interview_app/` через PyInstaller `--onedir`.
3. Зашьёт `ffmpeg.exe`, `keywords.json`, `interruptions/`.

Переносимая папка `dist/interview_app/` целиком копируется на любой
Windows 10/11 — работает без установленного Python.

> `--onedir`, а не `--onefile`: ffmpeg и модель тяжёлые, `--onefile`
> при каждом запуске распаковывается во временную папку — медленно.

## Ограничения

- Whisper на CPU без GPU: 15-минутное видео обрабатывается ~3–6 мин.
  Для ускорения — `whisper_device: "cuda"` и `whisper_compute_type: "float16"`
  (нужна видеокарта NVIDIA).
- Точность silence detection зависит от фонового шума. Тюньте `silence_db`.
- Перебивки любого разрешения приводятся к `output_resolution` автоматически
  (с чёрными полосами по бокам, если пропорции другие).
