# InterviewKit Go

Локальное приложение для расшифровки и ручного монтажа интервью.

## Как работает

1. Видео выбирается из `incoming/` или по полному пути.
2. Go-приложение извлекает звуковую дорожку через локальный `bin/ffmpeg.exe`.
3. Нативный Go/C++ движок Whisper распознаёт речь локально.
4. В GUI появляется таймлайн с текстом и таймкодами после установки движка.
5. Между любыми фрагментами можно вручную вставить видео из `interruptions/`.
6. FFmpeg нормализует фрагменты и собирает `final.mp4`.

Внешние LLM и облачные API не используются. Видео, звук и текст не покидают компьютер.

## Запуск

После клонирования один раз скачайте нативный runtime и модель:

```bat
install_runtime.bat
```

Затем запустите приложение:

```bat
run_go.bat
```

Приложение откроет локальный GUI в браузере. Сервер слушает только
`127.0.0.1` и недоступен другим компьютерам в сети.

## Сборка

```bat
build_go.bat
```

Готовый файл: `bin/interviewkit.exe`.

Запускайте его из корня проекта, чтобы рядом были папки:

- `bin/ffmpeg.exe`;
- `bin/whisper/Release/whisper-cli.exe` и DLL;
- `models/ggml-small-q5_1.bin`;
- `incoming/`;
- `interruptions/`;
- `interviews/`.

## Перебивки

Скопируйте видео в `interruptions/`. Файлы показываются в GUI под своими
именами, поэтому их удобно называть так, как они звучат: например,
`gorko.mp4`, `aplodismenty.mp4`, `deneg_reshayut.mp4`.

Перебивка вставляется кнопкой **«+ Перебивка»** в любом промежутке таймлайна.
Её можно заменить, удалить или перетащить в другое место. Если у файла есть
аудиодорожка, она сохраняется; для немого файла добавляется тишина.

После нового распознавания каждое слово показывается отдельной кнопкой. Нажмите
на нужное слово и выберите файл перебивки: исходный видеосегмент будет разделён
после окончания слова с небольшим защитным запасом, а перебивка окажется между
двумя частями. Старые проекты без word timestamps нужно распознать заново.

Кнопка **«Вырезать текст»** включает удаление по расшифровке: выберите первое и
последнее слово удаляемого диапазона и подтвердите операцию. Из монтажного плана
будет удалён соответствующий интервал видео, а материал до и после него
сохранится.

## Формат проекта

Для каждого интервью создаётся папка `interviews/<дата>_<имя>/`:

- `raw.*` — копия исходника;
- `audio.wav` — извлечённый звук;
- `project.json` — расшифровка и ручной монтажный план;
- `final.mp4` — собранный результат.

## Движок STT на Windows

Python-адаптер удалён; приложение не запускает Python. Распознавание выполняет
нативный Windows x64 `whisper.cpp` CLI из `bin/whisper/Release/` с локальной
multilingual-моделью `models/ggml-small-q5_1.bin`. Для русского языка
используется параметр `-l ru`, вычисления выполняются на CPU без GPU.

Старый Python/CTranslate2 pipeline удалён. Тяжёлые runtime-файлы и модель не
хранятся в Git и устанавливаются скриптом `install_runtime.bat`.
