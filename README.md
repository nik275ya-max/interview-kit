# InterviewKit

Программа для автоматического монтажа свадебных/праздничных интервью с прикольными
видео-перебивками.

**Сценарий работы:** вы записываете интервью на телефон/камеру, готовый mp4
кладёте в папку `incoming/` — программа извлекает аудио, распознаёт речь
локальной нейросетью Whisper, а языковая модель (LLM через polza.ai) выбирает
лучшие реплики и вставляет между ними видео-перебивки из папки
`interruptions/`. На выходе — один смонтированный фильм на интервью.

## Возможности

- Локальное распознавание речи (faster-whisper) — расшифровка не покидает компьютер.
- Автоматическая нарезка речи по паузам (silence detection).
- Умный монтаж нейросетью (polza.ai): LLM сама выбирает лучшие реплики,
  вырезает заполнители и решает, какую перебивку вставить (см. ниже).
- Просмотр расшифровки и ручная правка перебивок перед сборкой.
- Автоматическое обновление списка при появлении файлов в `incoming/`.
- Переносимая сборка в один `.exe` (без установленного Python).

## Структура папок

```
interview_kit/
├── interview_app.py        # точка входа + GUI
├── core/                   # модули ядра
│   ├── paths.py            # разрешение путей
│   ├── config.py           # конфигурация
│   ├── ffmpeg_wrapper.py   # обёртка над ffmpeg
│   ├── stt.py              # локальный Whisper
│   ├── llm.py              # умный монтаж через LLM (polza.ai)
│   ├── editor.py           # план монтажа и сборка
│   └── pipeline.py         # оркестрация пайплайна
├── config.example.json     # пример настроек (при первом запуске → config.json)
├── requirements.txt
├── build.bat               # сборка в exe
├── interruptions/          # все видео-перебивки в одной папке (имя файла = метка для LLM)
├── incoming/               # сюда кладёте свежие записи (один mp4 = одно интервью)
├── interviews/             # сюда складываются результаты
└── models/                 # модель Whisper для офлайн-работы
```

## Запуск из исходников

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python interview_app.py
```

Требуется установленный **ffmpeg** в PATH, либо положите `ffmpeg.exe` в
`bin\ffmpeg.exe` рядом с проектом.

> ⚠️ При первом запуске модель Whisper (`small`) скачается автоматически
> (~500 МБ) в кэш HuggingFace. Для офлайн-сборки см. раздел ниже.

## Использование

1. Положите видеозапись интервью в папку `incoming/`
   (например `2026-10-27_Иван.mp4`).
2. Запустите программу, выберите файл в списке, укажите имя гостя.
3. Нажмите **«Подготовить расшифровку»** — программа извлечёт аудио,
   распознает речь и построит план монтажа.
4. Во вкладке **«Расшифровка»** проверьте текст и перебивки:
   любую перебивку можно заменить на другую или убрать.
5. Нажмите **«🎬 Собрать итоговое видео»** — получите `final.mp4`
   в папке `interviews/<дата>_<гость>/`.

## Нарезка видео по сценам

Для графического интерфейса запустите:

```bat
python scene_splitter_app.py
```

В Windows также можно запустить `run_scene_splitter.bat`.

В окне можно добавить видео или папку, настроить поиск сцен, просмотреть
таймкоды кнопкой «Анализировать» и выполнить нарезку. Интерфейс не блокируется
во время обработки.

Отдельный скрипт находит визуальные монтажные склейки и сохраняет сцены как
`scene_0001.mp4`, `scene_0002.mp4` и т. д. Результат по умолчанию создаётся
рядом с видео в папке `<имя>_scenes/`:

```bat
python split_scenes.py "incoming\video.mp4"
```

Порог `--threshold` задаёт чувствительность: меньшее значение находит больше
смен. Для динамичных роликов попробуйте `0.25`, для спокойных — `0.45`:

```bat
python split_scenes.py video.mp4 --threshold 0.30 --min-duration 1.5
python split_scenes.py incoming --recursive --output scenes
python split_scenes.py video.mp4 --analyze-only
```

По умолчанию фрагменты перекодируются для точных границ. Флаг `--copy` ускоряет
нарезку без перекодирования, но границы могут смещаться к ключевым кадрам.
Файл `scenes.json` содержит таймкоды всех созданных частей. Для замены прежнего
результата используйте `--overwrite`.

Чёрный экран длительностью от 0,2 секунды в начале или конце исходного видео
удаляется автоматически. Чёрные переходы внутри ролика не удаляются. Отключить
обрезку можно флагом `--keep-edge-black`.

## Перебивки

Все видео-перебивки (b-roll) лежат **в одной папке** `interruptions/`, без
категорий и подпапок. Нейросеть выбирает, какую перебивку вставить после
реплики, исходя из содержания расшифровки и **имён файлов** — поэтому давайте
файлам говорящие имена (например `gorko.mp4`, `romantika.mp4`,
`deneg_reshayut.mp4`). Чем понятнее имя, тем точнее выбор.

Тестовые заглушки можно сгенерировать скриптом:

```bat
.venv\Scripts\python.exe generate_placeholders.py
```

## Умный монтаж нейросетью (polza.ai)

Монтажом управляет языковая модель (LLM) через [polza.ai](https://polza.ai) —
OpenAI-совместимый сервис. Модель читает расшифровку интервью и сама решает:

- какие реплики оставить (лучшие, законченные ответы),
- какие вырезать (заполнители, хезитации «эээ», повторы, отступления от темы),
- после каких реплики вставить видео-перебивку и **какую именно** (по имени
  файла из папки `interruptions/`).

Склеивание по-прежнему делает FFmpeg локально — нейросеть управляет только
планом монтажа, а не генерирует видео. Распознавание речи остаётся локальным
(Whisper), поэтому в интернет уходит только текст расшифровки.

### Включение

1. Зарегистрируйтесь на [polza.ai](https://polza.ai) и получите API-ключ.
2. Пропишите ключ в `config.json`:

```json
{
  "polza_api_key": "ваш-ключ",
  "polza_model": "deepseek/deepseek-v4.1-flash-1017"
}
```

`polza_model` — любая чат-модель из каталога polza.ai. Дешёвая и быстрая
(`deepseek/...`, `anthropic/claude-haiku-5.5`) отлично справляется с выбором
монтажа; для более тонкого отбора можно поставить модель подороже.

### Поведение и запасные варианты

- Если `polza_api_key` пустой или LLM недоступна (сеть, лимиты, некорректный
  ответ), программа **автоматически откатывается**: оставляет все реплики без
  перебивок — пайплайн не падает.
- Решения LLM можно проверить и поправить во вкладке «Расшифровка» перед
  сборкой: заменить перебивку на другую или убрать её.

## Настройки

Кнопка **«Настройки»** в программе или правьте `config.json` напрямую:

| Параметр | Описание |
|----------|----------|
| `whisper_model` | Размер модели: `tiny`/`base`/`small`/`medium`/`large-v3` |
| `silence_db` | Порог тишины (dB). Громче праздника → меньше порог (напр. -25) |
| `silence_min_duration` | Мин. длительность паузы, сек |
| `fallback_segment_sec` | Длина отрезка, если пауз нет (монолог) |
| `output_resolution` | Разрешение итогового видео |
| `output_fps` | FPS итогового видео |
| `watch_incoming` | Автоматически обновлять список файлов в `incoming/` |
| `polza_api_key` | API-ключ polza.ai (без него монтаж работает без перебивок) |
| `polza_model` | Модель polza.ai для монтажа (напр. `deepseek/deepseek-v4.1-flash-1017`) |

## Офлайн-сборка модели Whisper

Чтобы exe работал без интернета на чужом компе:

1. Один раз запустите программу из исходников (с интернетом) — модель
   скачается в кэш.
2. Либо скачайте CTranslate2-модель вручную и положите в `models/small/`
   (должен быть файл `model.bin`).
3. После сборки exe скопируйте папку `models/` рядом с `interview_app.exe`.

Программа сначала ищет модель в `models/<имя>/`, и только если её нет —
пробует скачать.

## Сборка в exe

```bat
build.bat
```

Скрипт:
1. Установит зависимости.
2. Соберёт `dist/interview_app/` через PyInstaller `--onedir`.
3. Зашьёт `ffmpeg.exe`, `interruptions/`, `config.example.json`.

Переносимая папка `dist/interview_app/` целиком копируется на любой
Windows 10/11 — работает без установленного Python.

> `--onedir`, а не `--onefile`: ffmpeg и модель тяжёлые, `--onefile`
> при каждом запуске распаковывается во временную папку — медленно.

## Ограничения

- Whisper на CPU без GPU: 15-минутное видео обрабатывается ~3–6 мин.
  Для ускорения — `whisper_device: "cuda"` и `whisper_compute_type: "float16"`
  (нужна видеокарта NVIDIA).
- Точность silence detection зависит от фонового шума. Тюньте `silence_db`.
- Перебивки любого разрешения приводятся к `output_resolution` автоматически
  (с чёрными полосами по бокам, если пропорции другие).
